## 1. 원칙

- 사용자가 직접 개발함. Claude는 단계별 설명, 코드 리뷰, 지시받은 부분 작성만 맡음.
- 순서는 아래 표를 따르되, 다음 단계로 넘어갈지는 사용자가 정함.
- 처음부터 끝까지 MSW 목 데이터로 개발하고, 실제 API는 마지막에 연결함.
- 단계마다 `pnpm format:check`, `lint`, `typecheck`, `test`, `build` 통과 후 커밋함. push는 사용자가 함.
- 단계가 끝나면 [implementation.md](implementation.md)의 화면 현황을 갱신함.
