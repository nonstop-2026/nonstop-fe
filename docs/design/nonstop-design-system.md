# 논스톱 디자인 시스템

버전 0.3 / 2026-11-09

값은 `nonstop-design-tokens.md`에 있고, 이 문서는 그 값을 언제 어떻게 쓰는지 정한다. 이 문서는 노션 개발문서 와이어프레임 v3의 색, 탭, 마스코트, 하이라이트 규칙을 대체한다. 화면 흐름처럼 이 문서가 다루지 않는 부분은 노션 문서를 따른다.

## 1. 방향

논스톱은 IT 관련 분야 학부생과 대학원생이 매일 논문 한 편을 읽는 루틴 서비스다. 사용자가 믿어야 하는 것은 논문 내용이고, 계속 돌아오게 만드는 것은 출석 스트릭이다. 그래서 화면을 두 영역으로 나누고 각 영역에 허용되는 표현을 다르게 둔다.

| 영역 | 해당 화면 | 허용 | 금지 |
| --- | --- | --- | --- |
| 읽기 면 | 피드, 논문 카드, 논문 상세, 저장함 목록 | 잉크 계열, 형광펜 한 줄 | 마스코트, 살구색 면, 장식 |
| 루틴 면 | 출석 스트릭, 온보딩, 빈 화면, 오류 화면 | 살구색 면 하나, 마스코트 | 살구색 외의 색 추가 |

학술적인 인상은 세리프나 크림색 종이 같은 소품이 아니라 읽기 면의 절제와 정확한 표기(arXiv 분류 코드, 인용 형식의 메타데이터, 정렬된 숫자)에서 만든다.

## 2. 데모 범위의 전제

| 항목 | 내용 |
| --- | --- |
| 로그인 | 없음. 회원 가입, 동의 화면, 탈퇴가 없음 |
| 사용자 데이터 | 관심 키워드, 기본 읽기 수준, 저장 목록, 출석 기록은 브라우저에만 저장 |
| 테마 | 라이트 모드만 사용하고 검수함. 피드도 라이트 |
| 빠진 기능 | 알림, PWA, 검색, 폴더, 좋아요, 챗봇, 편집팀 해설, 개정판 배지, 화제의 논문 |

## 3. 색 사용 규칙

1. 화면 면적의 대부분은 잉크 계열이다. 살구색 면(`bg-accent`)은 한 화면에 하나만 둔다.
2. 형광펜(`bg-highlight`)은 논문 하나당 핵심 한 줄(`oneLine`)에만 쓴다.
3. 오류 빨강(`text-danger`)은 오류 문구에만 쓴다. 초기화 같은 위험한 버튼도 빨갛게 칠하지 않고 확인 시트의 문구로 알린다.
4. 성공, 경고, 정보 색은 없다. 아이콘과 문구로 전달한다.
5. 색만으로 의미를 전달하지 않는다. 선택된 칩은 채움과 글자 색이 함께 바뀌고, 스트릭 칸 옆에는 일수가 표시된다.
6. 그라데이션, 반투명 유리 효과, 발광 효과, 글자 그림자는 쓰지 않는다.

## 4. 서체 규칙

1. 모든 텍스트는 Pretendard 하나로 쓴다.
2. 위계는 크기와 굵기로만 만든다. 강조를 위해 색을 바꾸지 않는다.
3. 논문 제목은 `text-paper-title`(20px, 650)을 쓰고, 영어 원제는 그 아래 `text-caption text-fg-tertiary`로 항상 함께 표기한다. 한국어 제목은 AI가 만든 것이므로 원제가 기준이다.
4. arXiv ID, 날짜, 일수, 개수에는 `tabular-nums slashed-zero`를 적용한다.
5. 수식이 있으면 수식 구간만 KaTeX로 렌더링한다. `$...$` 문자열을 그대로 노출하지 않는다.

## 5. 레이아웃

| 항목 | 값 |
| --- | --- |
| 기준 화면 폭 | 375px (최소 360px까지 깨지지 않을 것) |
| 데스크톱 | 가운데 `max-w-app`(480px) 폭 |
| 좌우 여백 | `px-5` |
| 섹션 간격 | 32px |
| 최소 터치 영역 | 44 x 44px |
| 화면 높이 | `h-dvh` 기준. `h-screen`(100vh) 금지 |
| 안전 영역 | 하단 탭과 고정 버튼에 `env(safe-area-inset-bottom)` 반영 |

## 6. 모양과 깊이

| 요소 | 라운드 | 구분 방식 |
| --- | --- | --- |
| 버튼, 입력창, 세그먼트 | `rounded-control` | 채움 또는 1px 테두리 |
| 카드 | `rounded-card` | 1px 구분선, 그림자 없음 |
| 바텀시트, 토스트 | `rounded-card` | `shadow-overlay` |
| 칩, 배지 | `rounded-pill` | 1px 테두리 또는 채움 |
| 형광펜, 스트릭 칸 | `rounded-mark` | 채움 |

카드 안에 카드를 넣지 않는다. 목록은 카드를 반복하지 않고 행 사이 구분선으로 처리한다.

## 7. 움직임

공들이는 장면은 두 곳으로 한정한다.

| 장면 | 동작 |
| --- | --- |
| 출석 스트릭 갱신 | 일수 숫자가 한 칸 올라가고 오늘 칸이 채워짐 (`duration-320 ease-out`) |
| 카드 스와이프 | 온보딩 카드는 손가락을 따라 움직이고, 놓으면 관성으로 빠짐 |

그 외 상태 변화는 `duration-150` 또는 `duration-200`, `ease-out`. 반복 애니메이션, 화면 진입 시 일괄 페이드, 스크롤 연출, 원형 스피너는 쓰지 않는다. `motion-reduce:`에서는 즉시 전환한다.

## 8. 아이콘

| 항목 | 규칙 |
| --- | --- |
| 형태 | 선 아이콘 한 종류 (현재 `shared/ui/icons`의 직접 작성 SVG 유지) |
| 선 굵기 | 1.75 고정 |
| 크기 | 20px (목록, 버튼 안), 24px (하단 탭, 헤더) |
| 아이콘만 있는 버튼 | `aria-label` 필수, 터치 영역 44px |

유니코드 기호나 이모지를 아이콘 대신 쓰지 않는다. 불꽃 아이콘은 쓰지 않는다.

## 9. 마스코트

| 항목 | 규칙 |
| --- | --- |
| 사용 위치 | 첫 화면, 온보딩 완료, 스트릭 기념 순간(7일, 30일), 빈 화면, 오류 화면 |
| 금지 위치 | 피드, 논문 카드, 논문 상세, AI 요약 영역, 로딩 (로딩은 스켈레톤) |
| 최소 크기 | 3D 렌더 원본은 48px 이상에서만 사용 |
| 파비콘 | 16px, 32px은 얼굴과 학사모만 남긴 단순화 버전 필요 (원본 축소 시 식별 불가 확인함) |
| 표정 | 데모는 기본, 축하 2종. 오류·빈 화면은 기본 표정 사용 |
| 접근성 | 장식용이면 `alt=""` |

## 10. 컴포넌트

### 10.1 Button

| 변형 | 클래스 요지 | 용도 |
| --- | --- | --- |
| primary | `bg-primary text-on-primary` | 화면의 주요 행동 하나 |
| secondary | `border border-line-control text-fg` | 보조 행동 |
| text | `text-fg-secondary` | 건너뛰기, 나중에 하기 |
| accent | `bg-accent text-on-accent` | 루틴 면에서만, 화면당 하나 |

높이 `h-12`, `rounded-control`, 라벨 한 줄, 눌림은 `active:scale-98`. 비활성 버튼보다 활성 상태를 유지하고 눌렀을 때 이유를 알려 주는 방식을 우선한다. 단, 관심 분야 3개 미만의 "다음" 버튼은 기존대로 비활성으로 두고 아래에 "3개 이상 골라 주세요"를 표시한다.

### 10.2 Chip

| 상태 | 클래스 요지 |
| --- | --- |
| 기본 | `border border-line-control text-fg` |
| 선택 | `bg-primary text-on-primary` |
| 강조 (온보딩 "흥미로워요") | `bg-accent text-on-accent` |

높이 `h-9`, 라벨 앞에 `#`을 붙이지 않는다.

### 10.3 PaperCard

구성 순서는 고정한다.

1. 상단 줄: arXiv 주 분류 코드(`cs.HC`), 학회·연도(있을 때), 오른쪽에 "AI 요약" 외곽선 배지
2. 한국어 제목 (`text-paper-title`)
3. 영어 원제
4. 형광펜 한 줄 (`oneLine`)
5. 메타데이터: `저자 (연도) · arXiv ID`, 가운뎃점은 하나만
6. 행동: 피드에서는 우측 레일(저장, 공유), 홈 카드에서는 카드 전체가 상세로 가는 링크

변형은 hero(홈 오늘의 논문), list(목록 행), swipe(온보딩), feed(피드 전체 화면) 네 가지다. list 변형은 카드 테두리 없이 행 구분선을 쓴다. hero, swipe, feed 변형은 카드 맨 위에 PaperCover(large)를 두고, list 변형은 행 왼쪽에 PaperCover(thumb)를 둔다.

### 10.4 PaperCover

논문 데이터로 프론트가 그리는 생성형 표지다. AI 이미지 생성이나 논문 그림은 쓰지 않는다.

| 요소 | 규칙 |
| --- | --- |
| 분야별 모양 | `cs.AI` 연결된 노드, `cs.CL` 길이가 다른 글줄, `cs.CV` 픽셀 격자, `cs.HC` 겹치는 두 원, `cs.SE` 들여쓰기된 코드 줄 |
| 논문별 변화 | `paperId`의 해시를 난수 씨앗으로 써서 위치와 길이를 바꾼다. 같은 논문은 항상 같은 표지 |
| 색 | 배경 `bg-surface-muted`, 선과 면은 `line-divider`, `fg-tertiary`, `highlight`. 살구색(`accent-graphic`)은 표지마다 요소 하나에만 |
| 글자 | 왼쪽 위 분류 코드(`text-headline`)와 분야 이름, 왼쪽 아래 arXiv ID(`tabular-nums slashed-zero`), 오른쪽 아래 키워드 최대 2개 |
| 크기 | large는 16:9 (`aspect-video`), thumb는 56px 정사각형이며 글자 없음 |
| 접근성 | 장식용이므로 `aria-hidden`. 같은 정보는 카드 본문에 글자로 있다 |

표지의 살구색은 면이 아닌 그래픽 요소로 보며, 3절의 "살구색 면은 한 화면에 하나" 규칙에 세지 않는다. 그라데이션, 사진, 일러스트, 마스코트는 표지에 쓰지 않는다. 구현은 `PaperCover.tsx`를 기준으로 한다.

### 10.4.1 Highlight

`oneLine`에만 쓰는 인라인 요소. `bg-highlight rounded-mark box-decoration-clone px-1`.

### 10.5 StreakStrip

| 요소 | 규칙 |
| --- | --- |
| 일수 | `text-display tabular-nums`, "12일째" 형식 |
| 주간 칸 | 월~일 7칸. 완료 `bg-accent-graphic`, 미완료 `bg-surface-muted`, 오늘 미완료는 `border-2 border-accent-graphic` |
| 안내 문구 | `text-accent-fg`. 오늘 미인정이면 "오늘 한 편 읽으면 13일째예요", 인정 후에는 "오늘도 읽었어요" |
| 배경 | `bg-accent-soft rounded-card` |
| 접근성 | 칸 그룹에 "이번 주 4일 읽음" 형식의 `aria-label` |

홈 상단과 메뉴(최장 기록 포함)에 둔다. 0일이면 "오늘 첫 논문을 읽어 보세요"를 표시한다.

### 10.6 LevelSelector (읽기 수준)

쉽게, 기본, 전문 세 단계. 시각적으로는 슬라이더 형태지만 마크업은 `role="radiogroup"`과 라디오 3개로 두어 좌우 방향키와 스크린리더로 조작할 수 있게 한다. 상세 화면과 메뉴의 기본 읽기 수준 설정에 같은 컴포넌트를 쓴다.

### 10.7 나머지

| 컴포넌트 | 규칙 요약 |
| --- | --- |
| BottomNav | 홈, 피드, 저장함, 메뉴 4탭. 아이콘과 라벨 함께, 선택 탭은 `text-fg font-semibold` |
| TopBar | 뒤로, 제목, 오른쪽 아이콘 하나까지 |
| BottomSheet | 상단 `rounded-card`, 손잡이, 닫기 버튼 필수 (드래그만으로 닫지 않음) |
| Toast | 3~5초, 행동 버튼 하나까지, `role="status"` |
| Badge | 외곽선형만. 데모에서는 "AI 요약" 하나 |
| RankedKeywords | 온보딩 완료의 상위 관심 키워드. 비율 막대 대신 1~3위 순위 목록 |
| EmptyState | 마스코트, 무엇을 하면 채워지는지 한 문장, 행동 버튼 하나 |

## 11. 상태

모든 데이터 화면은 다음 상태를 정의해야 완료로 본다.

| 상태 | 표현 |
| --- | --- |
| 로딩 | 최종 레이아웃과 같은 모양의 스켈레톤 (`bg-surface-muted`) |
| 서버 깨우는 중 | 첫 요청이 3초를 넘으면 스켈레톤 위에 "서버를 깨우는 중이에요. 잠시만 기다려 주세요" |
| 빈 화면 | EmptyState |
| 오류 | 무엇이 안 됐는지와 "다시 시도" 버튼, 마스코트 기본 표정 |
| 콘텐츠 대체 | 응답의 `isFallback`이 참이면 홈 상단에 "최근 논문을 모았어요" 한 줄 |

## 12. 제스처

| 위치 | 제스처 | 대체 수단 |
| --- | --- | --- |
| 피드 | 위·아래 스와이프로 이전·다음 논문 (scroll-snap) | 위·아래 방향키 |
| 피드 | 오른쪽 스와이프로 상세 (화면 왼쪽 가장자리 20px 안에서 시작한 제스처는 무시) | 카드 탭, 오른쪽 방향키 |
| 온보딩 | 좌·우 드래그로 별로·흥미로워요 | 하단 버튼 3개, 좌·우 방향키 |
| 상세 | 뒤로 가기는 브라우저 기본 동작 (상세는 별도 URL) | 상단 뒤로 버튼 |

두 번 누르기(좋아요)와 길게 누르기 메뉴는 데모에서 쓰지 않는다. 피드 안에서 같은 논문의 카드를 가로로 넘기는 방식도 쓰지 않는다. 가로 제스처는 상세 진입 하나만 쓴다.

## 13. 접근성

| 항목 | 기준 |
| --- | --- |
| 텍스트 대비 | 4.5:1 이상 (토큰 문서 2.4절의 조합만 사용) |
| 경계선, 그래픽 대비 | 3:1 이상 |
| 포커스 | `outline-2 outline-offset-2 outline-focus`. 제거 금지 |
| 확대 | `user-scalable=no` 금지 |
| 키보드 | 모든 조작을 키보드로 가능하게 |

## 14. 문구

| 규칙 | 예 |
| --- | --- |
| 해요체 | 저장했어요 |
| 버튼은 동사로 시작 | 읽기, 저장, 다시 시도, 시작하기 |
| 같은 행동은 같은 이름 | 버튼 "저장" / 토스트 "저장했어요" |
| 오류는 원인과 다음 행동 | 논문을 불러오지 못했어요. 다시 시도해 주세요 |
| 빈 화면은 안내로 | 마음에 드는 논문을 저장하면 여기에 모여요 |
| 금지 | 줄표(—, –), 느낌표, 이모지, "성공적으로", 한 줄에 가운뎃점 두 개 이상 |
| AI 생성물 | 항상 "AI 요약" 배지 |
