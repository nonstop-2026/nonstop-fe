| 영역        | 사용 기술                        | 용도                                       |
| ----------- | -------------------------------- | ------------------------------------------ |
| 화면        | React, TypeScript                | 컴포넌트 기반 화면 구성                    |
| 빌드        | Vite                             | 개발 서버, 배포용 빌드                     |
| 라우팅      | React Router                     | 주소와 화면 연결, 하단 탭 레이아웃         |

| 기기 저장   | Zustand `persist`                | 프로필 · 저장 목록 · 출석 기록 · 읽은 논문 |
| 애니메이션  | Motion                           | 온보딩 카드 드래그, 스트릭 갱신            |
| 목 서버     | MSW                              | 백엔드 없이 개발 · 시연                    |
| 테스트      | Vitest, Testing Library          | 단위 · 컴포넌트 테스트                     |
| 코드 품질   | ESLint, Prettier, jsx-a11y       | 정적 검사, 코드 모양 통일, 접근성 검사     |
| 패키지 관리 | pnpm                             | 설치 · 명령 실행                           |
| CI · 배포   | GitHub Actions, Firebase Hosting | PR 검사, 정적 파일 배포                    |

## 2. 화면 구현 현황

| 경로                    | 화면             | 상태   |
| ----------------------- | ---------------- | ------ |
| `/`                     | 시작             | 미구현 |
| `/onboarding/interests` | 관심 분야 선택   | 미구현 |
| `/onboarding/swipe`     | 카드 10장 평가   | 미구현 |
| `/onboarding/done`      | 취향 분석 완료   | 미구현 |
| `/home`                 | 홈               | 미구현 |
| `/feed`                 | 피드             | 미구현 |
| `/papers/:paperId`      | 논문 상세        | 미구현 |
| `/saves`                | 저장함           | 미구현 |
| `/menu`                 | 메뉴             | 미구현 |
| `/menu/keywords`        | 관심 키워드 관리 | 미구현 |
| `/menu/settings`        | 설정             | 미구현 |
| `/terms`                | 이용약관         | 미구현 |
| `/demo`                 | 시연 도구        | 미구현 |
| `*`                     | 404              | 미구현 |

- 상태 값: 미구현, 진행 중, 완료(목 데이터 기준), 연동 완료(실제 API 기준).

## 3. 코드 구조

```
src/
├─ app/          라우터, 레이아웃(AppShell, TabLayout), 전역 스타일(디자인 토큰)
├─ features/     화면 단위 기능
│  ├─ start/       시작
│  ├─ onboarding/  관심 분야 · 카드 평가 · 완료
│  ├─ home/        홈
│  ├─ feed/        피드
│  ├─ paper/       논문 상세
│  ├─ saves/       저장함
│  ├─ menu/        메뉴 · 관심 키워드 · 설정
│  ├─ terms/       이용약관
│  └─ demo/        시연 도구
├─ shared/
│  ├─ api/         apiFetch, 쿼리 훅, 응답 타입
│  ├─ store/       기기 저장(profile, saves, streak, read)
│  ├─ lib/         출석 판정(streak.ts) 등 순수 함수
│  ├─ ui/          공통 컴포넌트
│  └─ config/      환경 변수
├─ mocks/        MSW 핸들러와 목 데이터
└─ test/         Vitest 설정
```

- 기능 폴더끼리는 서로 import하지 않음. 여러 화면이 쓰는 것은 `shared/`에 둠.
