# 논스톱 상호작용 · 상태 정의

| 항목      | 내용                                                                                                       |
| --------- | ---------------------------------------------------------------------------------------------------------- |
| 문서 버전 | 0.1                                                                                                        |
| 기준 시점 | 2026-11-11                                                                                                 |
| 근거      | 팀 피드백(동작이 딱딱 끊김, 버튼인지 알기 어려움), 디자인 시스템 0.3의 7절 움직임                          |
| 관련 문서 | [design/nonstop-design-system.md](design/nonstop-design-system.md), [implementation.md](implementation.md) |

컴포넌트마다 상태를 나누고, 상태가 바뀔 때의 동작을 정한다. 코드는 이 문서를 따르고, 동작을 바꾸면 이 문서를 같이 고친다.

## 1. 공통 원칙

| 항목        | 규칙                                                                                                                     |
| ----------- | ------------------------------------------------------------------------------------------------------------------------ |
| 시간        | 색 변화 · 눌림 150ms, 화면 전환 · 진행 막대 200ms, 출석 스트릭 갱신 · 바텀시트 320ms                                     |
| 곡선        | 모두 `ease-out` (`cubic-bezier(0.22, 1, 0.36, 1)`)                                                                       |
| 눌림        | 버튼 `active:scale-98`, 아이콘 버튼 `active:scale-95`, 카드 `active:scale-99`                                            |
| hover       | 마우스가 있는 기기에서만 적용된다 (Tailwind 4 `hover:`). 터치 기기에서는 눌림만 보인다                                   |
| 포커스      | 키보드 포커스에만 2px `outline-focus` 외곽선 (`:focus-visible`)                                                          |
| 동작 줄이기 | 기기 설정의 동작 줄이기가 켜져 있으면 위치 이동 없이 바로 바뀐다 (`motion-reduce:`, `MotionConfig reducedMotion="user"`) |
| 금지        | 반복 애니메이션, 요소를 하나씩 순서대로 띄우는 진입 연출, 스크롤 연출, 원형 스피너                                       |

## 2. 화면 전환

| 이동                                                   | 동작                                                         | 구현 위치                   |
| ------------------------------------------------------ | ------------------------------------------------------------ | --------------------------- |
| 새 화면으로 들어감 (상세, 하위 메뉴, 온보딩 다음 단계) | 화면 전체가 오른쪽 16px에서 제자리로, 투명도 0에서 1 (200ms) | `app/layouts/AppShell.tsx`  |
| 뒤로 가기 (브라우저 뒤로, 상단 뒤로, 다 읽었어요)      | 왼쪽 16px에서 제자리로, 투명도 0에서 1 (200ms)               | `app/layouts/AppShell.tsx`  |
| 하단 탭끼리 이동                                       | 탭 안쪽 내용만 투명도 0에서 1 (150ms). 하단 탭은 그대로      | `app/layouts/TabLayout.tsx` |
| 피드 탭으로 이동                                       | 하단 탭 배경이 어두운 색으로 바뀜 (200ms)                    | `app/layouts/TabLayout.tsx` |
| 바텀시트 열기 · 닫기                                   | 아래에서 올라옴 · 내려감 (320ms), 뒤 배경은 투명도만         | `shared/ui/feedback.tsx`    |
| 토스트                                                 | 아래 8px에서 올라오며 나타남 (200ms), 4초 뒤 사라짐          | `shared/ui/feedback.tsx`    |

## 3. 컴포넌트 상태

### 3.1 Button

| 변형      | 기본                                    | hover                         | 눌림       | 비활성                                         |
| --------- | --------------------------------------- | ----------------------------- | ---------- | ---------------------------------------------- |
| primary   | `bg-primary text-on-primary`            | 투명도 90%                    | `scale-98` | `bg-surface-muted text-fg-tertiary`, 눌림 없음 |
| secondary | 1px `line-control` 테두리, `bg-surface` | `bg-surface-muted`            | `scale-98` | 테두리 `line-divider`, 글자 `fg-tertiary`      |
| text      | `text-fg-secondary`                     | `bg-surface-muted`, 글자 `fg` | `scale-98` | 글자 `fg-tertiary`                             |
| accent    | `bg-accent text-on-accent`              | 투명도 90%                    | `scale-98` | 투명도 50%                                     |

비활성 상태에서는 커서가 `not-allowed`로 바뀐다.

### 3.2 Chip (관심 키워드)

| 상태  | 동작                                                |
| ----- | --------------------------------------------------- |
| 기본  | 1px `line-control` 테두리, `rounded-control`        |
| hover | `bg-surface-muted`                                  |
| 선택  | `bg-primary text-on-primary`, 라벨 앞에 체크 아이콘 |
| 눌림  | `scale-98`                                          |

알약 모양이 많다는 피드백에 따라 칩은 `rounded-pill` 대신 `rounded-control`을 쓴다.

### 3.3 Segmented (읽기 수준, 저장함 기간)

| 상태          | 동작                                                         |
| ------------- | ------------------------------------------------------------ |
| 틀            | `bg-surface-muted`, 1px `line-divider` 테두리, 안쪽 여백 4px |
| 선택 안 된 칸 | `text-fg-secondary`, hover 시 `bg-surface text-fg`           |
| 선택된 칸     | `bg-primary text-on-primary font-semibold`                   |
| 눌림          | `scale-98`                                                   |
| 키보드        | 좌우 · 위아래 방향키로 이동하며 바로 선택                    |

읽기 수준은 선택한 단계의 설명을 아래에 한 줄로 보여 준다.

### 3.4 아이콘 버튼 · 상단 뒤로 가기 · 피드 레일

| 상태  | 동작                                                |
| ----- | --------------------------------------------------- |
| 기본  | 44px 터치 영역, 글자색 `fg` 또는 `fg-secondary`     |
| hover | `bg-surface-muted`, 글자 `fg`                       |
| 눌림  | `scale-95`                                          |
| 켜짐  | 저장된 논문은 북마크 아이콘을 채움 (`aria-pressed`) |

### 3.5 하단 탭

| 상태       | 동작                                        |
| ---------- | ------------------------------------------- |
| 선택 안 됨 | `text-fg-tertiary`, hover 시 `fg-secondary` |
| 선택       | `text-fg font-semibold`, 아이콘 채움        |
| 눌림       | `scale-95`                                  |

### 3.6 논문 카드 · 목록 행 · 메뉴 행

| 대상                   | hover                      | 눌림                       |
| ---------------------- | -------------------------- | -------------------------- |
| hero 카드 (홈, 저장함) | 테두리 `line-control`      | 카드 `scale-99`            |
| list 행 (홈 추천)      | 행 배경 `bg-surface-muted` | 행 배경 `bg-surface-muted` |
| 메뉴 행                | 행 배경 `bg-surface-muted` | 행 배경 `bg-surface-muted` |

이미 상세를 연 논문은 한국어 제목을 `text-fg-tertiary`(회색)로 낮추고, 카드 윗줄(목록 행은 분류 줄 오른쪽)에 체크 아이콘과 "읽음"을 표시한다. 기준은 기기에 저장된 최근 읽은 논문 50편(`nonstop:v1:read`)이다. 홈은 읽은 논문을 서버 요청에서 빼므로(`exclude`) 읽은 논문이 다시 나오지 않고, 피드와 저장함에서 회색 제목으로 보인다.

저장함 hero 카드는 저장 날짜와 저장 취소 버튼을 카드 본문 아래 구분선 밑 별도 줄(footer)에 둔다. 버튼이 본문 위에 겹치지 않게 하기 위해서다.

### 3.6.1 오늘의 논문 가로 넘김 (홈)

| 상태         | 동작                                                                                    |
| ------------ | --------------------------------------------------------------------------------------- |
| 구성         | 카드 폭 5/6, 다음 카드가 오른쪽에 살짝 보임. 아래에 이전 버튼 · 위치 점 · 다음 버튼     |
| 터치         | 브라우저 가로 스크롤과 scroll-snap으로 한 장씩 넘김                                     |
| 마우스 끌기  | 40px 넘게 끌면 끈 방향으로 한 장 넘김(부드러운 스크롤). 끈 뒤의 클릭은 상세로 가지 않음 |
| 버튼         | 이전 · 다음. 처음과 끝에서는 비활성(투명도 40%)                                         |
| 위치 점      | 현재 카드는 넓은 점(`w-4 bg-primary`), 나머지는 작은 점. 바뀔 때 200ms                  |
| 한 편뿐일 때 | 넘김 없이 카드 한 장만 표시                                                             |

오늘의 논문 묶음은 홈 응답의 `todayPaper`와, 추천 중 `todayPaper`와 게시일이 같은 논문(최대 4편)이다. 나머지 추천은 "나를 위한 추천" 영역(흰 바탕, 위 구분선)에 목록으로 둔다.

### 3.7 피드

| 상태               | 동작                                                                                                              |
| ------------------ | ----------------------------------------------------------------------------------------------------------------- |
| 화면               | 어두운 배경(`.theme-dark`)에 분류 · 제목 · 원제 · 한 줄 요약 · 방법 · 핵심 포인트 2개 · 키워드 · 저자를 글로 표시 |
| 방법 · 핵심 포인트 | 보고 있는 논문과 앞뒤 한 편만 상세 API로 미리 받는다. 받는 동안 글줄 스켈레톤                                     |
| hover              | "자세히 보기" 글자가 `fg-secondary`에서 `fg`로                                                                    |
| 탭                 | 상세로 이동                                                                                                       |
| 오른쪽 스와이프    | 60px 이상, 가로 이동이 세로의 1.5배를 넘으면 상세로 이동. 왼쪽 가장자리 20px에서 시작하면 무시                    |
| 위 · 아래          | 한 장씩 스냅, 3장 남으면 다음 묶음 요청                                                                           |

### 3.8 온보딩 카드 평가

| 상태              | 동작                                                                                                                                                      |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 대기              | 안내 문구 "왼쪽으로 밀면 별로예요, 오른쪽으로 밀면 흥미로워요"                                                                                            |
| 끄는 중           | 카드가 손가락을 따라 움직이고 최대 6도 기울어짐. 오른쪽으로 끌면 왼쪽 위에 "흥미로워요", 왼쪽으로 끌면 오른쪽 위에 "별로예요" 라벨이 거리에 비례해 진해짐 |
| 놓음 (110px 미만) | 제자리로 돌아감                                                                                                                                           |
| 놓음 (110px 이상) | 같은 방향으로 날아가며(200ms) 다음 카드                                                                                                                   |
| 버튼              | 별로예요(왼쪽 화살표) · 건너뛰기 · 흥미로워요(오른쪽 화살표), 방향키 좌우도 같음                                                                          |
| 되돌리기          | 한 번만 가능. 쓴 뒤에는 비활성                                                                                                                            |

### 3.9 논문 상세 끝

| 요소        | 동작                                                          |
| ----------- | ------------------------------------------------------------- |
| 원문 보기   | secondary 버튼. arXiv 초록 페이지를 새 탭으로 연다            |
| 다 읽었어요 | primary 버튼. 들어온 화면으로 돌아간다. 이전 기록이 없으면 홈 |

## 5. 디자인 시스템 0.3과 다르게 구현한 부분

팀 피드백(2026-11-11)을 반영하며 디자인 시스템 원본과 달라진 부분이다. 원본 문서는 고치지 않고 여기에 기록한다.

| 디자인 시스템 0.3                             | 현재 구현                                                                  |
| --------------------------------------------- | -------------------------------------------------------------------------- |
| 피드도 라이트, 카드 맨 위에 PaperCover(large) | 피드는 어두운 배경에 글만, 표지 없음                                       |
| 칩 · 배지는 `rounded-pill`                    | 칩 `rounded-control`, AI 요약 배지 `rounded-mark`                          |
| 읽기 수준은 슬라이더 모양                     | 세그먼트 버튼 모양 (마크업은 radiogroup 그대로)                            |
| 화면 진입 시 일괄 페이드 금지                 | 화면 단위로 한 번만 짧게 전환 (2절). 요소별 순차 연출은 여전히 쓰지 않는다 |
| 바깥 배경 토큰 없음                           | `backdrop`(ink-100) 추가, 앱 영역 좌우 구분선                              |
| 기본 읽기 수준은 설정 화면                    | 메뉴 화면에 바로 표시                                                      |
| 가로 제스처는 피드에서 상세로 가는 것 하나만  | 홈 오늘의 논문은 가로로 넘긴다 (3.6.1)                                     |
